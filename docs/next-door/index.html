Next Door

A data center wants to move in. Before the public hearing, see what it could mean for your town's electricity, water, jobs and taxes, in plain numbers, with every source linked.

How this was made: built with Claude, Anthropic's AI assistant, which checked each assumption against public sources, wrote the formulas and drew the charts. Chris Truong chose the subject, directed the work and reviewed it before publishing. Figures are planning-level estimates, not predictions for a specific project.
